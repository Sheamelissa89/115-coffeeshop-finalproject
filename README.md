# ☕ Copper & Bean Coffee House

Copper & Bean is a responsive coffee shop website originally created for the final project in FSDI 115: UX Design and Responsive Design. It was later enhanced during FSDI 116 to demonstrate iterative development using Agile and Scrum practices.

The project demonstrates the complete design and development process—from user research, personas, user flows, and wireframe sketches to a polished, responsive, and functional website.

## Project Overview

Copper & Bean is a fictional neighborhood coffee shop focused on locally roasted coffee, fresh food, and community connection.

The website allows visitors to:

- Learn about the coffee shop
- Explore menu categories and prices
- Read the company story and values
- View the location, hours, phone number, and email
- Navigate smoothly between page sections
- Submit a message through the contact form
- Calculate a suggested or custom tip
- Divide a bill between multiple guests
- Use the website across desktop and mobile screen sizes

## Website Sections

### Home

Introduces the Copper & Bean brand with a welcoming hero image, short value statement, and calls to action.

### Menu

Displays customer favorites in three easy-to-scan categories:

- Coffee
- Cold Drinks
- Fresh Food

### Tip Calculator

Provides an interactive tool that allows users to:

- Enter a bill amount
- Select a suggested tip of 15%, 18%, 20%, or 25%
- Enter a custom tip percentage
- Divide the total between multiple people
- View the tip amount, total with tip, and amount per person
- Reset the calculator to its default values

The calculator validates user input and formats the results as United States currency.

### About

Explains the story behind Copper & Bean and highlights its commitment to:

- Local ingredients
- Freshly roasted coffee
- Community connection

### Contact

Provides the shop’s:

- Address
- Business hours
- Phone number
- Email address
- Contact form

## UX Design Process

The original project followed a complete user experience design process:

1. Defined the business problem and project goals
2. Identified the target audience
3. Conducted fictional user and competitor research
4. Created owner and employee personas
5. Translated user needs into website requirements
6. Designed a user flow
7. Created low-fidelity wireframe sketches
8. Selected the color palette and typography
9. Planned responsive desktop and mobile layouts
10. Built and tested the website

## Agile and Scrum Enhancement

During FSDI 116, the website was improved through an additional development increment. The tip calculator was selected as a customer-focused feature that added practical value to the existing coffee shop website.

The enhancement included:

1. Defining the feature as a user need
2. Dividing the feature into HTML, CSS, JavaScript, testing, and responsive-design tasks
3. Adding the calculator to the website navigation
4. Creating the calculator interface
5. Implementing the calculation and reset logic
6. Testing preset and custom tip percentages
7. Verifying bill-splitting calculations
8. Testing the responsive mobile layout
9. Reviewing the completed working increment
10. Identifying improvements through reflection

## Design System

The website uses a warm coffee-inspired color palette:

- Espresso Brown: `#3B2216`
- Copper: `#BE6538`
- Cream: `#FBF6EE`
- Gold: `#EFA94A`
- Sand: `#EADBC8`

Editorial-style headings are paired with clean sans-serif body text to create a balance between warmth and readability.

## JavaScript Functionality

JavaScript supports the interactive parts of the website, including:

- Mobile navigation behavior
- Contact-form submission feedback
- Automatic footer year display
- Suggested tip selection
- Custom tip calculations
- Bill splitting between multiple guests
- Currency-formatted results
- Input validation
- Calculator reset functionality

## Responsive Design

The layout adapts for different screen sizes.

On larger screens, content is displayed in columns to make effective use of the available space. On smaller screens, the navigation, menu cards, images, text, contact content, calculator fields, buttons, and calculation results stack vertically for improved readability and usability.

## Functional Testing

The tip calculator was tested with preset and custom tip percentages.

### Preset Tip Test

- Bill amount: $50.00
- Tip percentage: 20%
- Number of people: 2
- Tip amount: $10.00
- Total with tip: $60.00
- Amount per person: $30.00

### Custom Tip Test

- Bill amount: $50.00
- Custom tip percentage: 22%
- Number of people: 2
- Tip amount: $11.00
- Total with tip: $61.00
- Amount per person: $30.50

The reset button was also verified to restore the calculator to an 18% suggested tip, one person, blank inputs, and $0.00 results.

## Running the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser or with the Live Server extension.
4. Use the navigation links and buttons to explore each section.
5. Open the Tip Calculator section to test the interactive feature.
